# House Price Predictor (Ames, Iowa)

Gradio app from the *Classroom to Industry: Build, Train & Deploy ML Models* workshop.
It estimates sale prices for homes in Ames, Iowa, using a Random Forest trained on historical
sales (2006-2010). Test-set average error: about $19,630.

This is a learning project, not a current property valuation service.
Data: https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/data
